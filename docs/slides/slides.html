Limitations

ScopeOne model, one prompt per condition, one seed, two languages.
Causal claimsLanguage and prompt wording confounded. No English question with Hindi reasoning.
Data2,250-question subset for added sets. Hindi distractors not literal.
MeasurementRegex parser and script labels. One LLM annotator, no human validation.
InterventionsWrong traces only. Quantised self-hosted model.
Thinking10 questions per cell. Thinking and budget change together.
